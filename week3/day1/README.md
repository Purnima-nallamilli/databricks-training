

## 🎯 Learning Objectives
- Understand ranking and analytical functions in SQL  
- Learn how to assign row numbers and ranks  
- Analyze data within groups using partitions  

---

## 🧠 Concepts Learned

### 🔹 ROW_NUMBER()
- Assigns a unique number to each row  
- Used for ordering and pagination  

### 🔹 RANK()
- Assigns rank with gaps for duplicate values  
- Useful for leaderboard scenarios  

### 🔹 DENSE_RANK()
- Assigns rank without gaps  
- Used when continuous ranking is needed  

### 🔹 PARTITION BY
- Divides data into groups  
- Performs calculations within each group  

### 🔹 ORDER BY in Window Functions
- Controls ranking and numbering order  

---

## 🚀 Outcome
- Ability to rank and analyze data efficiently  
- Understanding differences between ranking functions  
- Strong foundation for analytical SQL queries
