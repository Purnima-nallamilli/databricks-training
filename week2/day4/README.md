

## 🎯 Learning Objectives
- Strengthen SQL query writing skills  
- Understand real-world data analysis scenarios  
- Apply advanced SQL concepts for problem-solving  

---

## 🧠 Concepts Learned

### 🔹 Joins
- INNER JOIN, LEFT JOIN for combining multiple tables  
- Handling missing data using joins  

### 🔹 Filtering & Conditions
- Using `WHERE`, `HAVING`, `IS NULL`, `IS NOT NULL`  
- Applying conditional logic with `CASE`  

### 🔹 Aggregations
- Using `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`  
- Grouping data using `GROUP BY`  
- Filtering grouped data with `HAVING`  

### 🔹 Subqueries
- Writing nested queries  
- Comparing values with overall and group averages  

### 🔹 Sorting & Limiting
- Ordering results using `ORDER BY`  
- Finding top and nth highest values  

### 🔹 Window Functions
- `ROW_NUMBER()`, `RANK()`, `DENSE_RANK()`  
- `NTILE()`, `PERCENT_RANK()`, `CUME_DIST()`  

### 🔹 Analytical Functions
- Running totals using `SUM() OVER()`  
- Moving averages and cumulative calculations  

### 🔹 Navigation Functions
- Using `LAG()` and `LEAD()`  
- Comparing previous and next records  

### 🔹 Advanced Filtering
- Identifying top performers and outliers  
- Comparing individual performance with group averages  

---

## 🚀 Outcome
- Ability to solve complex SQL problems  
- Strong understanding of analytical queries  
- Improved confidence in handling real-world datasets  
- Preparedness for technical interviews and data roles
