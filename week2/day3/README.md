
## 🎯 Learning Objectives
- Understanding how NULL values behave in SQL  
- Learning techniques to handle missing or incomplete data  
- Writing efficient queries to manage NULL scenarios  

---

## 🧠 Concepts Learned

- Filtering NULL values using `IS NULL` and `IS NOT NULL`  
- Replacing NULL values using `IFNULL`  
- Using `COALESCE` to return the first non-NULL value  
- Using `NULLIF` to convert specific values into NULL  
- Handling NULL values in calculations and expressions  
- Avoiding errors like division by zero using `NULLIF`  
- Writing conditions involving multiple NULL checks  

---

## 🚀 Outcome
- Ability to handle missing data effectively in SQL queries  
- Improved query accuracy when working with real-world datasets  
- Better understanding of NULL behavior in filtering and calculations
