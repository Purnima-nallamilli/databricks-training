
## 🎯 Learning Objectives
- Understand pattern matching using SQL Regular Expressions  
- Extract meaningful data from complex text fields  
- Apply regex in real-world data cleaning scenarios  

---

## 🧠 Concepts Learned

### 🔹 Basic Pattern Matching
- Using `REGEXP` and `REGEXP_SUBSTR`  
- Identifying patterns in strings  

### 🔹 Anchors
- `^` → Start of string  
- `$` → End of string  

### 🔹 Character Classes
- `[0-9]` → Digits  
- `[a-zA-Z]` → Alphabets  
- Combining patterns for flexible matching  

### 🔹 Quantifiers
- `+` → One or more  
- `{n}` → Exact number of occurrences  

### 🔹 String Extraction
- Extracting:
  - Numbers from strings  
  - Alphabets from mixed values  
  - Specific positions (start, end, middle)  

### 🔹 Email Parsing
- Extracting username  
- Extracting domain  
- Extracting extension  

### 🔹 Phone Number Parsing
- Extracting country codes  
- Handling special characters like `+`  

### 🔹 Advanced Extraction
- Extracting data between characters  
- Extracting continuous sequences  
- Combining regex with string functions  

---

## 🚀 Outcome
- Strong understanding of regex in SQL  
- Ability to clean and transform messy text data  
- Improved problem-solving skills for real-world datasets  
- Confidence in handling pattern-based queries
